# Pong

Ce dépôt contient un mini-jeu de Pong jouable directement dans le navigateur.

## Lancer le jeu

1. Ouvrez `index.html` dans votre navigateur favori.
2. Utilisez les touches **W** et **S** pour déplacer la raquette de gauche.
3. Utilisez les flèches **↑** et **↓** pour déplacer la raquette de droite.
4. Appuyez sur la **barre d'espace** pour mettre en pause ou reprendre la partie.

Amusez-vous bien !
